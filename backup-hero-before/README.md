# Supercar Insurance Sale Page

หน้าเว็บ HTML/CSS/JavaScript ที่ขึ้นจาก Figma node `308:1210`

## เปิดใช้งาน

เปิด `index.html` ได้โดยตรง หรือรัน local server:

```bash
python3 -m http.server 8080
```

แล้วเปิด `http://localhost:8080`

## ไฟล์หลัก

- `index.html` — โครงสร้างและเนื้อหาหน้าเว็บ
- `styles.css` — ดีไซน์ responsive desktop/mobile
- `script.js` — แกลเลอรี popup และ FAQ accordion
